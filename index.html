Library Installation

Ensure you have Python >= 3.8 installed. Run the following installation commands inside your terminal to sync core image processing libraries:

pip install -r requirements.txt
pip install -e .

Core Architecture Pipelines

1. DentalDicomReader

Loads clinical DICOM files and instantly masks patient demographic fields for strict KVKK/GDPR compliance.

2. DentalImagePreprocessor

Applies localized CLAHE contrast boosters and edge-preserving filters to draw micro-caries patterns cleanly.

Programmatic Quick Start

Executing an automated 32-tooth radiology pass and initializing a signed verification tracking process:

from universal_dental_ai.core import DentalDicomReader, DentalInferenceEngine

reader = DentalDicomReader()
pixels, patient_meta, tech_meta = reader.read_secure_pipeline("xray.dcm")

engine = DentalInferenceEngine()
findings = engine.predict_radiograph(pixels)

Doctor Validation Workflow

The library implements an immutable FindingStatus architecture. Predictions remain locked as AI_PROPOSED until a dentist modifies or approves the coordinates, shifting states to DOCTOR_APPROVED or DOCTOR_REJECTED. PDF builders discard any rejected entities automatically.
